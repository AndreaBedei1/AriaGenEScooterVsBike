# data/public - staging for explicitly prepared releases (NOT versioned)

Only data that went through the release procedure in `docs/privacy_pipeline.md`
(anonymised media, derived metrics, generalised or relative trajectories, re-checked
for identifiers) may be placed here, together with a release note describing what was
removed or generalised. Public releases are published through a data repository
with its own licence and DOI - never through this git repository.

The release procedure and the decision to share any data are **TBD** (ethics
committee, DPO and data management plan).
