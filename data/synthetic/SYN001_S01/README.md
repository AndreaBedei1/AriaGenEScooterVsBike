# SYN001_S01 - SYNTHETIC / TEST DATA

**This folder contains artificial data. It is NOT experimental data and must
never be analysed, reported or shared as if it were.**

Generated by `ariagen_escooter.synthetic` (seed 20261006, speed scale 1.0) to
test the software without Aria hardware. Regenerate with:

```
python -m ariagen_escooter make-synthetic
```

Contents: `manifest.yaml`, canonical streams (`<recording>/streams/*.csv`),
annotations (`<recording>/annotations/*.csv`), label maps
(`<recording>/semantic/labels.npz`) and `ground_truth.json` (the values the
pipeline should recover). Coordinates are placed in the Adriatic Sea on purpose.
Known simplifications are listed in `ground_truth.json`.
